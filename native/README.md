# Native allocator sources
The C++ library implements CUDA Driver VMM, native source/cache/ring/batch transport
and event-protected PyTorch allocation. This is implemented code, not a scaffold.
See [contracts](../docs/developer/contracts.md), [builds](../docs/developer/builds.md)
and [validation](../docs/developer/validation.md). Do not run historical probes
or overwrite accepted binaries merely because compilation succeeds.
